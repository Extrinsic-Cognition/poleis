## What it writes

`votes/release-<commit's 12>-<member>.json`, the Keystone page's prepared format (the same as an act's vote set): `act` names the release (`"n":
"release"`, its hash), so the page holds every transaction's bytes to that hash; `release` names the commit, root 0, the nonce, SIGNAL under CONSENT,
kind 0x52. Transaction 1, its proposal (`propose_nft` by the member's first seat); then one PRO (`attest_nft`) a seat. Each is the client's own
builder byte for byte (`tests/release.rs`).
